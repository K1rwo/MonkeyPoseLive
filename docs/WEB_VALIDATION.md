# 远程网页工程验证（2026-10-20）

这是软件验证记录，不是关键点准确率或摄像头性能报告。桌面v0.1.0的既有验证见 [VALIDATION.md](VALIDATION.md)。

## 实际本机模型与视频

在隔离的私有目录启动独立网络服务，通过真实HTTP、cookie和CSRF接口提交已有15秒猴子短片，使用既有W32模型和CPU YOLO，不训练或微调：

- 五种模型均能从既有配置识别为已就绪；本轮网络链路实际使用W32进行推理。
- 原视频224帧全部进入模型，导出224条JSONL结果；原始17通道与显示15点规则保持。
- 有限坐标、原图尺寸与处理尺寸、处理画面像素坐标系记录检查通过。
- 下载的CSV与结果点数一致；下载的叠加视频完整解码224帧。
- 使用既有视频的三张JPEG模拟浏览器摄像头提交，返回序号、画面与骨架对齐；未打开实体摄像头。
- 摄像头不保存坐标时无JSONL／CSV，停止后IPC图片被清理。
- 两个独立浏览器会话的任务访问隔离，退出一个会话不影响另一个登录。

这些检查共13项通过。研究媒体和预测留在本地受控目录，测试没有将它们发到公网。

## 传输与访问控制

本地完整Python回归77项（桌面原有40、远程HTTP33、Web发行包4）及前端34项（桌面15、远程19）通过；另有PowerShell启动器回归，分别在PowerShell7与WindowsPowerShell5.1通过。

真实HTTP测试覆盖未登录访问、错误口令、Host／Origin、CSRF、cookie撤销和过期、分会话任务与下载权限、路径穿越、重复安全头、请求长度、分块重试、取消中的上传、摄像头尺寸限制、HEAD与连接复用、登录频率及本地管理令牌。使用替代引擎验证访问隔离，测试不会开启摄像头或模型。

前端回归覆盖分块上传、停止中的异步请求、摄像头串行发送与序号检查、模型排队、轨迹断点、ROI等比显示、退出时释放摄像头以及会话任务恢复。实体远程摄像头、来自另一台设备的网络路由和长期服务稳定性仍需现场验证。

临时HTTPS入口实际在浏览器中登录，显示五个既有模型；上传12帧合成视频后页面显示12帧完成，浏览器下载的结果视频完整读回12帧。合成素材明确标注为连接测试，不用其模型输出推断猴子关键点质量。公网往返没有传输研究媒体。

实际公网摄像头接口另提交3张合成JPEG，序号、17点输出和返回的对应JPEG均通过；任务列表只见本会话任务。公网无请求体的取消／退出登录和退出后401均通过，兼容隧道去掉Content-Length:0的情况。正在取消的任务在文件关闭后再开放下载。模型就绪信息及检查点核验元数据另存主机私有model_provenance.json，不作为远程下载文件发布。

## 运行边界

一次只运行一个模型任务，其他任务排队。每个会话最多3个未结束任务；上传视频不超过512MiB、10分钟或18000帧，输入不超过4096边长／8MP，处理画面最长边1280。数据目录配额5GiB，达到配额会拒绝新增任务或停止继续写入，由管理员归档已有文件。

浏览器摄像头只在任务运行时发送JPEG，一次最多一个在途请求，120秒无帧释放模型，每个任务最长1小时。自动定位没有验证个体身份；缺失、框外点、低分及长间隔会断开轨迹。

登录会话和任务索引存于进程内存：页面刷新可恢复当前会话任务；退出会话或服务重启后，网页不能再访问原会话任务。已有上传和结果仍保存在主机目录，供管理员管理，不自动删除。临时公网网址在连接器停止或重启后失效。
